Chapter 04

Directives & pipes

Built-in pipes for formatting, a custom pipe, and a custom attribute directive. Plus the [class.x] and [style.prop] shorthands you'll use every day.

Built-in pipes

  • currency → {{ price | currency:'EUR' }}
  • number:'1.2-2' → {{ price | number:'1.2-2' }}
  • percent → {{ rate | percent:'1.0-2' }}
  • date:'short' → {{ now | date:'short' }}
  • date:'yyyy-MM-dd HH:mm' → {{ now | date:'yyyy-MM-dd HH:mm' }}
  • titlecase → {{ 'hello world from angular' | titlecase }}
  • slice:0:20 → {{ longText() | slice:0:20 }}…

Custom pipe — truncate

{{ longText() | truncate:30 }}

{{ longText() | truncate:50:' […]' }}

Class and style bindings

I'm {{ isActive() | yesno }} at {{ fontSize() }}px

[class.active]="isActive()" toggles a class. [style.font-size.px] binds a style with a unit suffix.
